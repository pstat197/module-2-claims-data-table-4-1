HTML scraping

Including header content significantly improved model performance. Using logistic principal component regression on TF–IDF features, the baseline model trained only on paragraph text achieved 45.3% accuracy. After modifying the scraper to extract both paragraph text and all header tags (h1–h6), accuracy increased to 54.8% under the same stratified train/test split (seed 11172025). This improvement suggests that headers provide high-level cues—such as section titles, topic summaries, or claim-related phrasing—that are not always present in paragraph content but are highly informative for distinguishing claim vs. non-claim webpages.

Bigrams

To evaluate whether bigrams capture additional signal beyond single-word features, we built a two-stage model. First, we fit a logistic principal-component regression to the unigram TF–IDF matrix and extracted each page’s predicted log-odds. We then tokenized the cleaned text into bigrams, computed TF–IDF weights, reduced these features via PCA, and combined the bigram principal components with the unigram log-odds as predictors in a second elastic-net logistic regression. Cross-validated tuning selected similar regularization strengths for the unigram model (λ ≈ 0.01796) and the combined model (λ ≈ 0.02141), but including bigram features produced a very small improvement in predictive performance. The test AUC increased from 0.83258 (unigrams only) to 0.83263 (unigrams + bigrams), a gain of roughly +0.0001. This indicates that bigrams do contain some additional information relevant to the claim classification task, though the practical improvement is minimal.

Neural net

The neural network was trained on TF–IDF representations of the cleaned text. After preprocessing, each document was converted into a high-dimensional sparse feature vector (one column per token). These TF–IDF matrices were converted to dense matrices for neural-network training. The model architecture consisted of:

  • an input layer of dimension equal to the number of TF–IDF features in the training set;
  • a single hidden dense layer with 10 units (default linear activation), used to project the TF–IDF features into a lower-dimensional representation;
  • a 1-unit output layer with a sigmoid activation, producing the estimated probability that a document belongs to the positive class (“claim”).

The model was compiled using the Adam optimizer with default learning rate and binary cross-entropy loss, and trained with the binary_accuracy metric. Labels were converted to 0/1 according to the factor levels of the binary class variable. Training was performed for 20 epochs with a 20% validation split, using mini-batches of 32 across each epoch.

Based on the training history, the network reached a training accuracy of approximately 0.92, while the validation accuracy stabilized just under 0.80, indicating moderate overfitting but reasonable generalization. To assess out-of-sample performance, we evaluated the trained network on a held-out 20% test split of the original cleaned data. The resulting test accuracy was 0.80, closely matching the validation accuracy and confirming stable performance. This represents a substantial improvement over the Task 1 logistic PCR baselines (45–55% accuracy), demonstrating that the neural network is better able to capture nonlinear patterns in the TF–IDF feature space.
