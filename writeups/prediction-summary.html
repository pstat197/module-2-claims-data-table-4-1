Predictive modeling of claims status

Author

Lucy Cao, Kaitlyn Chihaoui, Alex Dieter, Srinidhi Sathish, Emily Tian

Published

November 18, 2025

Abstract

We used the cleaned text scraped from the webpages—containing paragraph and header content—and transformed it into TF–IDF features for predictive modeling. For the binary classification task, a regularized logistic regression (ridge) model achieved the highest accuracy at 77.18%, outperforming both a support vector machine and a recurrent neural network. For multiclass classification, an LSTM-based recurrent neural network performed best, achieving 60.26% accuracy, compared to 46.41% for regularized logistic regression and 44.87% for the SVM. These two models were selected as our final binary and multiclass classifiers and were exported in deployable form with corresponding predictions on the test dataset.

Preprocessing

We extracted both paragraph text and header tags from each page’s HTML. All text was lowercased and cleaned by removing punctuation, URLs, email addresses, digits, and excess whitespace, with camel-case separation performed as needed. The cleaned text was tokenized, lemmatized, stripped of stopwords, and converted into TF–IDF–weighted document-term matrices. These TF–IDF feature vectors served as the quantitative input representation for all models in the binary and multiclass prediction tasks. Feature names were saved to ensure consistent column alignment when applying the trained models to the test set.

Binary classification

For the binary setting, we compared three approaches: Support Vector Machine (SVM), regularized logistic regression, and an RNN. The SVM used a radial basis kernel and TF–IDF features, with hyperparameters tuned over a limited grid. The Regularized logistic regression model used ridge regularization with the tuning parameter λ chosen by cross-validation. This model was trained on the full TF–IDF matrix and produced linear decision boundaries in the principal-component-like feature space. The RNN used an embedding layer followed by an LSTM and dropout, but its validation accuracy was substantially lower than the ridge logistic model. Based on accuracy comparison, regularized logistic regression was selected as the final binary classifier.

Multiclass classification

For multiclass prediction, we again evaluated Support Vector Machine (SVM), regularized logistic regression, and an RNN. The SVM and logistic models were extended to the multiclass setting using the standard one-vs-rest formulation, with hyperparameters selected using cross-validation. The RNN-based model used word embeddings, an LSTM layer, and dropout regularization, trained with a categorical cross-entropy loss and the Adam optimizer. The RNN achieved the highest multiclass accuracy (60.26%), outperforming both linear and kernel methods, and was therefore selected as the final multiclass model. The multiclass RNN was exported as a .keras model for deployment.
